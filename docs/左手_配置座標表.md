# 左手 配置座標表（27キー）

## v2での変更

**COL0 / COL4 のスタガー量を実機に合わせて更新。** 初版は両方0mmとしていたが、
実基板では COL0 = 1.23mm / COL4 = 2.18mm 上にオフセットしている（意図的な調整）。
以下の表はすべて **PCB実測値**。

---

## 使い方

1. グリッド: **ユーザー定義 X = `18` / Y = `17/4` (=4.25)**
   ※ COL0 / COL4 は半端なオフセットなので、`E` キーで数値直接入力する
2. フットプリントを選択 → **`E` キー** → プロパティの位置 X / Y に数値入力
3. **原点(0,0) = COL2 × ROW0 (SW11 / `#`) の中心** = 最上段キー

## 列X座標とスタガー

| 列 | Col0 | Col1 | Col2 | Col3 | Col4 | Col5 | Col6 |
|---|---:|---:|---:|---:|---:|---:|---:|
| X (mm) | 0 | 18 | 36 | 54 | 72 | 90 | 108 |
| 指 | 小指 | 薬指 | 中指 | 人差 | 人差(内) | 親指 | 親指(内) |
| **上オフセット (mm)** | **1.23** | 8.5 | 12.75 | 4.25 | **2.18** | 0 | 0 |
| 右手の対応列 | — | Col4 | Col3 | Col2 | — | Col6 | Col7 |

- **中指列 (Col2) が最も高い**
- Col1 / Col2 / Col3 は右手と完全な鏡像（8.5 / 12.75 / 4.25）
- **Col0 と Col4 は左手独自**。小指列と人差し指内側列をわずかに持ち上げている
- 最下段 (Row4) は**スタガーなしのフラット行** — 全列 Y=80.75
- 行番号の向き: **Row0 = 最上段 / Row4 = 最下段**

### Y値の計算式

```
Row0〜Row3 :  Y = (12.75 + 17 × Row) − 列オフセット
Row4       :  Y = 80.75 （全列共通、オフセット無視）
```

## トラックパッド (φ30mm)

| 項目 | 値 |
|---|---|
| 中心 | **(102.50, 54.00)** |
| マーカー円 | φ30 / User.1 レイヤー |
| **銅ベタ キープアウト** | **φ34 / 中心同じ / F.Cu + B.Cu** |
| キープアウト設定 | 配線=許可 / ビア=禁止 / パッド=禁止 / **ベタ塗り=禁止** |
| 円内を通る配線 | **ゼロ**（実測確認済み） |
| マージン | パッド外周から 2.0mm 均等 |

静電容量式センサーの直下にソリッドGNDがあると寄生容量が増えて感度が落ちるため、
両面ともベタを抜いてある。
